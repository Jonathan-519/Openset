# TaxoSafe reference：研究依据、方法边界与验证路线

本轮主线是在已保留的 known-only 协议上，把成员性证据从“查询与聚合原型的关系”改为“查询与真实训练参考图片的关系”，并单独校准候选父类和候选物种的接受条件。实现与命令见 [运行说明](TAXOSAFE_REFERENCE.md)。这是待实验验证的研究方案，不是已达到四项门禁的论文结果。

## 1. 为什么继续改证据，而不仅是阈值

上一版 decoupled 已区分类别排名与绝对成员性，并取得了 known 端到端目标通过、三项未知相关目标未通过的真实实验结果。开发集还报告了固定分数、原联合两偏置解码下的 known／near 必要条件冲突。因此，本轮需要检验两个相互独立的假设：真实参考关系能否提高证据质量；候选成员性解码能否减少原联合概率竞争带来的停靠限制。

这一判断不能扩大为“所有原型方法失效”或“任何阈值都无解”。已有不可行诊断针对特定开发分数与特定解码器，换模型、换评分或换解码后需要重新测量。本轮不把历史 TEST 中某个物种的错误转化为该物种专属阈值，不把测试路径、来源名称或物种身份编码为拒识规则。

本轮另对上一版 v2 已保存的376张 **Dev** 原始头分数进行了两种解码诊断，使用预先声明的49分位数加两端点阈值网格；未使用 Test，也未重新训练参考关系网络：

| 旧 v2 Dev 指标 | 原联合两偏置解码 | 新成员性阈值诊断 |
| --- | ---: | ---: |
| known 正确叶 | 198/219 | 198/219 |
| near 正确父回退 | 35/69 | 36/69 |
| extra 正确根拒识 | 60/88 | 68/88 |
| 开放世界叶精确率 | 198/224 | 198/222 |

两者都未找到四项共同通过的点。这是“只改解码仍不足”的开发诊断，**不是 reference v3 的性能**，也不能把 extra 的变化归因于尚未训练的新参考模块。新方案仍需从 CLIP 完整训练后重新评估。

## 2. 一手论文给出的依据与不能照搬的部分

| 工作 | 可支持的判断 | 与本实现的区别 |
| --- | --- | --- |
| Lang 等，**From Coarse to Fine-Grained Open-Set Recognition**，CVPR 2024 | 语义距离和标签粒度会改变开放识别难度；层级监督对粗粒度与细粒度开放识别的影响并不一致。不能把“父类分类更准”直接等同于“同父未知更好拒识” | 本轮保留分层表示与不同深度监督，没有复现该文的完整层级对抗训练及 iNat2021-OSR 基准。见[官方论文页](https://openaccess.thecvf.com/content/CVPR2024/html/Lang_From_Coarse_to_Fine-Grained_Open-Set_Recognition_CVPR_2024_paper.html)、[作者项目页](https://langnico.github.io/fine-grained-osr/) |
| Huang 等，**Class-Specific Semantic Reconstruction for Open Set Recognition（CSSR）**，TPAMI 2023 | 在类别判别之外评估类别归属性有明确研究基础；该文以类别专属自编码器重建语义表示，通过重建误差描述类成员性 | 本轮没有自编码器或重建损失，成员性来自查询—参考对。不能把它命名为 CSSR 复现。见[作者论文](https://arxiv.org/abs/2207.02158)、[作者刊载信息](https://faculty.tju.edu.cn/wangyu_ai/en/lwcg/42127/content/52676.htm) |
| Sun 等，**Out-of-Distribution Detection with Deep Nearest Neighbors**，ICML 2022 | 已知样本参考距离是可行的非参数 OOD 证据，不必预设一个简单参数分布能够描述所有类别 | 本轮采用可训练双层关系匹配及类平衡聚合，不是原文的纯近邻距离检测器；top-k 参考本身不能称为新创新。见[PMLR 正式论文页](https://proceedings.mlr.press/v162/sun22d.html) |

| Lee 等，**Hierarchical Novelty Detection for Visual Object Recognition**，CVPR 2018 | 未知不必全部归入一个标签，可以定位到已知分类树的合适祖先；留类与重标注已有研究基础 | 本轮沿用既定两层分类树及支持干预，不能把留物种／留父类独立宣称为首次提出。见[作者论文](https://arxiv.org/abs/1804.00722) |
| Wallin 等，**ProHOC: Probabilistic Hierarchical Out-of-Distribution Classification via Multi-Depth Networks**，CVPR 2025 | 通过层级表示与概率模型，把已知送到叶、未知送到内部节点，是与本项目直接相关的比较方向 | 本实现只有一次共享视觉前向；新主解码是候选成员性阈值规则，没有复现其多深度网络及完整概率方法。见[CVF 论文页](https://openaccess.thecvf.com/content/CVPR2025/html/Wallin_ProHOC_Probabilistic_Hierarchical_Out-of-Distribution_Classification_via_Multi-Depth_Networks_CVPR_2025_paper.html)、[作者论文](https://arxiv.org/abs/2503.21397) |
| Pyakurel、Yu，**Learning State-Based Node Representations from a Class Hierarchy for Fine-Grained Open-Set Detection**，ICML 2025 | 该文指出简单逐层局部检测可能表现不佳，路径概率目标也有局限，并提出利用整棵树的状态表示 | 这是对本轮候选逐层 gate 的重要反向提醒：不能预设它普遍优于 joint，父排名错误仍会传递。必须保留 joint 控制实验；本轮没有复现该文的状态表示。见[PMLR 正式论文页](https://proceedings.mlr.press/v267/pyakurel25a.html) |

## 3. 实际方法：在两个深度学习真实参考关系

### 3.1 同一次图像编码，保留类别排名路径

共享 MaPLe/CLIP 视觉前向得到父层和叶层表示，继续使用已有 token 适配、池化、分类与候选排名路径。改变的是成员性评估：查询分别与参考库中真实 known TRAIN 图片比较，不先把所有参考压成一个平均原型，再要求一个分数同时承担分类和接受判断。

参考库仍有每叶数量上限；“真实 TRAIN 参考”指被选入支持库的真实训练图片，并不表示每次查询遍历整个 TRAIN。参考特征可缓存并 detach，真实查询路径保留梯度。单次主干前向限制了计算代价，但成对匹配及局部相似度仍增加开销，不能预先承诺与 v11 完全同速。

相对于上一版 decoupled，两个参考关系头替换原来的两个原型成员性头，默认头参数量不变；同一 batch 的参考关系在支持干预之间复用。公平速度报告仍要包含参考库重建、查询编码与关系计算，不能只报告 MLP 参数数或只计主干前向。

### 3.2 成对特征与受控聚合

父层与叶层各有一个在该深度内共享的关系头，输入是三个标量：全局余弦相似度、查询到参考的局部覆盖、参考到查询的局部覆盖。两个局部量分别对每个 token 的最佳跨图匹配相似度求平均，不使用 EMD。关系头不输入物种名称、来源路径或类别专属阈值。双向检查意在减少只在一个方向找到局部相似片段就提供充分支持的可能性，不证明 token 已对应真实解剖部位。

两个方向作为可学习输入，不是“两个方向必须分别超过某个硬阈值”的规则。关系头残差初始为零，起点主要由全局相似度先验决定；局部方向是否真正被学会使用，仍要由消融、梯度与训练后诊断验证。

对叶候选，在先排除查询同内容身份及干预移除参考后，取该叶有效参考中最高两个关系 logit 的平均。仅有一个有效参考时使用该参考，没有有效参考时该叶不活跃。父候选先对各子叶的父层关系做相同聚合，再对活跃子叶等权平均，避免训练图片多的物种直接主导父证据。top-2 是当前有限参考预算下的明确实现选择，不是论文已证明的最优值；参考不足、单叶父类和样本相关性必须在诊断中解释。

支持排除必须在参考参与候选选择、监督与聚合之前生效。成对相似度可以一次计算并复用，但被排除参考不能进入 top-k 或有效损失。不能把当前查询的另一条同内容路径当独立正参考，也不能在“移除物种”后继续让父统计携带该物种的信息。

### 3.3 真实成对监督与原有干预监督互补

完整支持条件上的关系监督直接提供如下标签：

| 深度 | 正对 | 负对与均衡 |
| --- | --- | --- |
| 叶层 | 同物种、不同内容图片 | 同父兄弟物种与不同父类分别作为负组，分组均衡，避免容易的跨父负对淹没细粒度负对 |
| 父层 | 同父不同物种 | 不同父类负对；单叶父类只能退回同物种正对，并记录此类监督覆盖不足 |

已有完整支持、缺叶、缺父和无关移除对照继续用于学习停靠深度；成对监督负责让关系头先学清楚真实参考关系。所有梯度图片来自 known TRAIN，真实 near/OOD 不参加这些损失。缺少有效正／负样本时，不伪造配对数量或自匹配。

直接成对损失使用完整支持条件下所有合法参考对，不仅训练最终 top-2 聚合选中的参考。top-k 决定候选接受证据的聚合，正负分组决定关系监督，两者不能混为同一采样过程。

### 3.4 候选一致的成员性解码

新主解码先按父类排名选择一个父类，再按该父内部的叶排名选择一个物种，这两个候选在比较阈值前固定。候选父类支持不足时到根；候选父类有支持、其候选叶支持不足时回退父类；父与叶均满足条件时输出该叶。候选不通过后不转而搜寻其他更容易通过阈值的父类或兄弟叶；因此错误的身份排名仍会限制最终性能。

两个阈值仅在既定 development 数据上校准，使用分位数候选网格与 known-first 选择策略。模型选择仍来自 known 验证，阈值选择与网络梯度训练分开。旧联合概率解码保留为独立对照；实现两种解码不代表已经完成公平消融，更不能按 TEST 结果挑选最终解码。

## 4. 如何判断是否真的有研究收益

固定数据、seed、参考预算和训练预算，分别检验以下因素；对照须明确自己改变了什么，不把整个新版本优于旧版本自动归因于单个模块。

| 比较因素 | 要回答的问题 |
| --- | --- |
| 聚合原型成员性与真实参考成员性 | 参考粒度改变是否提供更有效的归属证据？ |
| 参考成员性有／无直接成对监督 | 收益是否来自标签匹配，而不只是增加 MLP？ |
| 双向局部匹配与仅全局匹配 | 局部证据是否改善 near，且不损害 known？ |
| 相同训练机制下的新候选解码与旧联合解码 | 收益来自评分变化还是解码约束变化？当前完整配置受签名绑定，两种配置需独立 run；若要宣称严格同 checkpoint 对照，还需实现独立只读评分比较，不能在已有 run 原地换 decoder |
| 支持删类任务与严格 TRAIN 留类重训折 | 模型是否能迁移到该折微调阶段未见的类别？ |

严格 TRAIN 留物种／留父类工具已经存在，本轮工作是兼容新参考成员性；没有因此新增一批已完成的真实 GPU 留类结果。该工具保留未校准 joint argmax 诊断，并非正式 Dev 校准后的 membership decoder。全部折训练成本高于单次主训练，应预先声明所用折和种子，不能根据 held-out 结果反复挑有利折。

正式报告同时展示四项指标：known 端到端准确率 **>90%**、near 正确父回退 **≥85%**、extra 根拒识 **>90%**、开放世界叶精确率 **>90%**。报告每个 seed、逐物种／来源和推理时间；不把 AUROC 高、校准完成、CPU 测试通过或单个物种通过写成整体达标。已被历史研发分析过的 TEST 继续保持只测试权限，但不能重新称为研究全过程未查看的独立测试。

## 5. 候选贡献与限制

可以研究的整体贡献是：**在 known-only 训练和固定层级下，通过两个深度的真实参考关系监督，学习与候选节点一致的支持证据，再用明确的接受条件决定停靠层级。** 这一组合是否具有超出已有方法的价值，需要上述对照支持。

近邻支持、区域匹配、类成员性、类别留出和层级拒识分别已有文献或仓库实现，不能拆成多个未经验证的独立创新。参考分布仍不包含真正未知物种；关系网络也可能把背景或少数形态共性学成支持。单叶父类的同物种正对不能证明跨物种父类泛化。上述风险不会因为使用真实参考而自动消失。

本轮不保证四项 gate 通过，不宣称 SOTA，不声称完整复现 CSSR、DeepKNN、DeepEMD、HND 或 ProHOC。是否开始论文结果写作，应由统一协议下的真实实验和对照结果决定。
