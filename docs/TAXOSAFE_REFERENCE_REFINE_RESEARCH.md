# Reference v3 冻结精修：研究依据、实现边界与验证设计

本说明对应独立的 `TaxoSafe_reference_refine.yml` 配置。它以已经训练完成的 reference v3 为基线，冻结原有模型与父层决策，只研究类条件重构是否能改善细粒度叶类拒识。旧版 reference、relation 及原有训练入口保留。本轮没有新的真实图像训练与 TEST 性能结论，以下实验数字均来自此前完成的运行。

## 1. 为什么回到 reference v3

此前同口径 TEST 对比为：

| 验收指标 | reference v3 | relation v4 | 变化 |
| --- | ---: | ---: | ---: |
| 已知类端到端准确率 | 423/450，94.00% | 406/450，90.22% | −3.78 个百分点 |
| 近域未知正确父类回退率 | 124/204，60.78% | 115/204，56.37% | −4.41 个百分点 |
| 域外未知根拒识率 | 220/272，80.88% | 149/272，54.78% | −26.10 个百分点 |

更复杂的关系比较器没有在这次运行中带来收益，同时损害了原先较好的分类和域外拒识能力。因此，本轮不在 v4 上继续叠加关系头、对抗头或新的路由损失，而是把较好的 v3 状态作为不可更新的基线。

局部诊断还发现 learned local token 之间的余弦相似度超过 0.9999。当前 `TokenBranch` 用多个可学习查询对全部 patch 加权池化；多个池化结果高度重复时，增加它们之间的匹配统计并不等于增加独立的形态证据。这个观察针对已经导出的池化 token，**不能直接推出原始 ViT 的全部空间 patch 都已塌缩**。本轮默认使用冻结 v3 的全局 `fine` 特征，避免继续依赖这组近乎重复的局部输入。

这不是对训练轮数或阈值的单独调整：新增的是一种不同的成员资格测量，即“候选物种的受限重构器能否重构该图像的特征”。此前 v3 结果的详细定义和逐物种表见 [reference 实验复核](TAXOSAFE_RELATION_RESULT_REVIEW.md)。

## 2. 四篇一手研究提供了什么依据

### CSSR：本轮实际采用的主要思路

**Class-Specific Semantic Reconstruction for Open Set Recognition**，TPAMI，45(4)，2023，在线发表于 2022 年。

- [原论文](https://arxiv.org/pdf/2207.02158)
- [官方仓库](https://github.com/xyzedd/CSSR)
- [官方冻结主干实现，固定提交](https://github.com/xyzedd/CSSR/blob/d5a99e91f310ec274c7bfe5796fb270719a07ab3/methods/cssr_ft.py)
- [上述文件对应官方提交](https://github.com/xyzedd/CSSR/commit/d5a99e91f310ec274c7bfe5796fb270719a07ab3)

CSSR 用每类独立的瓶颈自编码器表示类别，重构语义特征而非原图；以 L1 重构误差构造分类证据。原文还实验了固定预训练主干、只训练分类层的方案。官方 `cssr_ft.py` 在 `fixbackbone=True` 时使用 `torch.no_grad()`，训练时令 backbone 保持 `eval()`，优化器只接收分类层参数。

本项目借鉴类条件语义重构与冻结精修方式。我们保留原分类身份和父层决策，重构模块只用于辅助叶类接纳；输入默认是已经 L2 归一化的全局 fine 向量。故应称为 **CSSR-inspired 冻结特征适配**，不是完整 CSSR 复现，也不能直接沿用论文中的收益数字。

### FRN：保留空间细节的备选，而非本轮叠加模块

**Few-Shot Classification with Feature Map Reconstruction Networks**，CVPR 2021。

- [CVPR 论文页](https://openaccess.thecvf.com/content/CVPR2021/html/Wertheimer_Few-Shot_Classification_With_Feature_Map_Reconstruction_Networks_CVPR_2021_paper.html)
- [论文全文](https://arxiv.org/html/2012.01506v2)
- [官方实现](https://github.com/Tsingularity/FRN/blob/main/models/FRN.py)

FRN 从同类支持图像的局部特征字典出发，用闭式 ridge regression 重构查询特征图，避免把全部空间细节提前平均成一个向量。其官方实现支持两种等价的矩阵计算形式。论文的细粒度小样本分类结果说明这种重构值得研究，但它本身不是未知拒识验证。

本轮没有加入 FRN。只有先确认原始 patch 含有可用的独立信息，再考虑以固定支持字典重构替代 learned local pooling；把四个近乎重复的 token 直接送入重构并不能恢复丢失的信息。完整字典还会增加求解和缓存开销。

### SCLIP：不能把 CLIP 的图像级能力等同于局部定位能力

**SCLIP: Rethinking Self-Attention for Dense Vision-Language Inference**，ECCV 2024。

- [ECCV 官方论文页](https://www.ecva.net/papers/eccv_2024/papers_ECCV/html/3178_ECCV_2024_paper.php)
- [论文](https://arxiv.org/abs/2312.01597)
- [官方代码](https://github.com/wangf3014/SCLIP/blob/main/clip/model.py)

SCLIP 针对 CLIP 的密集预测空间错位，在最后注意力层使用 query-query 与 key-key 相似度，复用原投影权重，无需额外训练。它说明局部特征的适用性需要单独验证。本项目没有替换 CLIP 的注意力层；分割任务的收益不能被当作浮游动物开集拒识的保证。

### ClearCLIP：共同通道可能掩盖局部差异

**ClearCLIP: Decomposing CLIP Representations for Dense Vision-Language Inference**，ECCV 2024。

- [论文全文](https://arxiv.org/html/2407.12442v1)
- [官方仓库](https://github.com/mc-lan/ClearCLIP)

ClearCLIP 分析了末层残差中少数高幅值通道对局部 cosine 的影响，并通过移除末层残差、FFN 和调整 self-self attention 改善密集预测。这给“高相似度并不必然表示局部形态一致”提供了机制依据，但不构成本项目已经证明同一故障原因的证据。本轮保持视觉主干原样。

## 3. 已选定的最小改动

### 冻结范围

作为基线的 v3 检查点、全部旧模型权重、原 support bank、候选父类与候选叶类的选择规则均保持冻结。父成员分数及基线父阈值也保持不变。新增训练不会更新 MaPLe prompts、编码器、parent/fine adapter、原分类器或原参考匹配器。

训练输入仅来自已知 TRAIN 图像经过冻结编码器生成的 fine 特征缓存。模型参数、support、类别顺序和输入来源需要有可核验的记录，不能把缓存文件名或目录名当作来源证明。DEV 和 TEST 不进入重构模块的梯度训练。

### 唯一新增的学习机制

每个已知物种使用一个无 bias 的低秩自编码器：

\[
A_c(z)=W^{\mathrm{dec}}_c\tanh(W^{\mathrm{enc}}_c z),
\qquad D\rightarrow16\rightarrow D.
\]

定义原始 L1 误差：

\[
e_c(z)=\lVert z-A_c(z)\rVert_1.
\]

用 \(-\alpha e_c(z)\) 构造辅助分类 logits，并对已知 TRAIN 标签优化负对数似然；\(\alpha>0\) 是可学习的正分类尺度。优化器为 Adam，初始学习率为 `1e-3`，最多训练 40 轮，早停 patience 为 8。只有 AE 与该正尺度进入优化器。训练中的辅助类别预测不替代 v3 的实际候选身份。

缓存内按内容哈希去重、按类别划分约 20% 图像作内部验证，用于选择重构模块的早停状态；单图类别留在拟合部分。由于 v3 编码器已经在原 TRAIN 上训练过，这个验证仅检查新 AE 的拟合，**不是独立主干验证，更不是未知物种验证**。不能将其称为严格留物种结果。

当 `D=512` 时，AE 参数为每类 `2×512×16=16,384` 个，另有一个共享的分类尺度。缓存训练不需要反复执行图像主干；部署仍然使用原有图像前向得到特征。参数与推理开销随已知类别数增长，实际速度和显存须在用户 GPU 上测量。

### 分数与原 CSSR 的区别

默认拒识分数为候选叶类的相对 L1 重构分数：

\[
s_{\mathrm{rec}}(z,c)=-\frac{e_c(z)}{\max(\lVert z\rVert_1,\epsilon)}.
\]

分数越大，表示相对重构误差越小。正分类尺度不参与最终拒识分数，防止将训练分类的尺度变化误当作绝对成员证据。零或近零输入不能因为分子也为零而获得高接纳分数。

原 CSSR 还利用特征幅值，其重构拒识分数包含平方 L1 范数分母。本项目输入已经经过 L2 归一化，不能未经验证照搬该幅值解释；因此默认使用上述相对误差。平方 L1 分母通过 `score_mode: cssr` 作为显式消融保留，不能根据 TEST 结果在两者之间选优。

## 4. 叶层双条件接纳与失败回退

设 v3 选出的候选父类、候选叶类分别为 \(p^*,c^*\)，原父成员分数为 \(s_p\)，原候选叶成员分数为 \(s_l\)。冻结的父阈值记为 \(\tau_p\)。

- 若 \(s_p(p^*)<\tau_p\)，仍输出根拒识。
- 父层通过时，只有 \(s_l(c^*)\ge\tau'_l\) **且** \(s_{\mathrm{rec}}(z,c^*)\ge\tau_{\mathrm{rec}}\) 才输出原候选叶类。
- 父层通过但任一叶条件不满足，输出原候选父类。

这里 `τ′l` 是精修阶段在 DEV 上选择的叶阈值，可以不同于原基线叶阈值；`τp` 保持冻结。重构器不能另选一个重构误差更小的物种来绕过当前候选，也不能把其他父类的证据借给当前路径。

两个叶层阈值只使用 DEV 校准。候选方案必须同时满足：

1. DEV 已知正确叶输出数不少于该校准基线，且已知端到端准确率严格高于 90%。
2. DEV 近域未知正确父类回退数不少于该校准基线。
3. DEV 开放场景叶类精确率不少于该校准基线。

如果没有满足条件的候选，新增门被禁用，恢复基线原叶阈值与原输出。禁用路径必须精确复现基线，不能留下额外过滤条件。以上是**精修启用条件**，不等于原研究四项验收门槛已经全部通过。

source leave-one-out 诊断中，基线校准和精修校准两个阶段都只允许使用 fitting sources。每折先重拟合该折基线校准，再固定该折父阈值、拟合两个叶条件；留出来源不得参与阈值网格、可行性判断或候选选择。该过程重拟合的是校准，不能误称为重新训练了未知物种未见的编码器。

## 5. 能改善什么，哪些问题本轮不解决

本轮希望在父类判断已经成立时，利用重构误差减少“外形接近但不属于该物种”的叶类误接纳。冻结分类及父层可减少再次损害已有能力的风险，但不能保证新的叶条件在 TEST 上无损保留所有已知样本。**DEV 不下降不构成 TEST 94.00% 的保证。**

在当前 v3 固定父候选与固定父阈值下，DEV 近域只有 52/69 张同时具备正确父候选且通过父门。因此，即使叶拒识完美，正确父类回退也至多为 **75.36%**，低于原定的 85% 门槛。剩余样本已经在父候选或父门阶段出错，新增叶拒识器无法修复。

同样，在相同数据与冻结父决策下，TEST 域外根拒识仍为 **220/272，80.88%**。精修可以把某些错误叶输出改成父输出，但这些样本仍不是正确的根拒识，不能计入域外成功数。

因此，这是一次范围明确的叶层机制实验，**在现有固定父决策下不可能使四项验收同时通过**。如果后续研究父层，应另行开展仅针对父层的严格留物种训练与验证，检验对未见物种的正确父类接纳；本轮不实现新的未知类 head，也不提前放宽验收门槛。

## 6. 如何判断这次修改是否有价值

首先检查来源与冻结不变量：v3 的原始分类分数、父成员分数、候选身份、support 引用与父阈值应保持一致；新优化器不得包含旧参数。禁用精修时，最终逐图输出必须回到基线。

随后分别报告：内部图像验证的 AE 拟合、DEV 启用条件、source leave-one-out 结果及冻结 TEST 结果。这四者含义不同。已知端到端准确率、近域正确父回退、域外根拒识和开放叶精确率仍按原定义计算；根拒的近域样本不能算作正确父回退。

最必要的对照是同一 v3 基线与启用精修后的结果，另报告默认相对误差和预先声明的平方范数消融。应同时检查逐物种结果、已知样本误拒变化与有效样本数量。更高的内部验证准确率、更多低重构误差样本或单元测试通过，都不能替代真实细粒度拒识提升。

如果新门在 DEV 不满足条件并被禁用，这也是有效结果：它表明在当前冻结表示上，该重构机制没有提供足够的额外判别信息。应保留这项负结果，而不是用 TEST 重新挑阈值或隐藏回退状态。
