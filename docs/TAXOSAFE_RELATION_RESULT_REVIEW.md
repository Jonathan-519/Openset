## 5. 开发集已经证明：当前阈值不能同时达标

下列必要条件来自固定DEV原始成员分数、固定候选身份的次序统计量，已独立复算：

| 要求 | 必要条件 |
| --- | --- |
| 已知>90%，至少198/219正确 | 叶接纳阈值≤4.20327759 |
| 近域≥85%，至少59/69正确 | 叶接纳阈值>6.88778305 |
| 保留足够近域正确父候选 | 父接纳阈值≤4.33107138 |
| 域外>90%，至少80/88根拒 | 父接纳阈值>7.04546547 |

叶阈值和父阈值均有互相矛盾的要求。保已知时，即使忽略父层拒识，近域正确回退的上界也只有40/69=57.97%。此结论限定于这份固定分数和候选规则，不是“任何未来模型都不可能”；它说明把49点网格加密或手动收紧阈值不能修复当前证据。

开发集来源留一诊断中，Centropages tenuiremis正确回退降至11/30=36.67%，Alima larva根拒降至10/16=62.50%。这种来源间波动提醒我们不能只报告一个总体分数。

## 6. 训练与源码定位

训练完成75轮，最优第50轮，累计约74.60分钟（按最终elapsed_seconds，不能逐轮累加）。最优轮已知DEV文本准确率98.17%，父/叶成员BCE为0.000748/0.004134，父/叶配对BCE为0.000827/0.021785。配对监督已产生大量有效梯度样本，并非未启用；代理训练任务接近饱和，真实未知泛化仍弱。

| 定位 | 证据与判断 | 修改或验证方式 |
| --- | --- | --- |
| 三标量配对头信息瓶颈 | 全局余弦、双向局部平均最大匹配都很高时，无法区分差异发生在哪些特征通道；这是确定的结构限制，尚非被消融证明的唯一主因 | 新增方向敏感、对称的投影向量差异和局部匹配残差 |
| 训练负对平均与推理最高参考池化不一致 | 推理按每类最高2个关系分数接纳，平均负对损失可能让少数高分负对被容易负对稀释 | 可选每类top-k困难负对BCE，保留正对覆盖和组间/类别间平衡 |
| 模型选择与候选分类器不同 | 旧选模按文本分类头，实际membership路由按支持候选父类和子类 | 新主配置按同一候选规则的known-only准确率选模 |
| 局部池可能冗余，未被证实 | 确有196个真实patch，经4个可学习注意力池压缩；包中没有局部向量，不能断言池已崩塌 | 新日志记录局部token相互余弦和正确叶—最难兄弟叶分数间隔 |
| 代理移除不等于真正未知 | drop-leaf/parent只移除支持，编码器仍训练过这些类 | 保留严格TRAIN类别留出重训协议，不能把低代理loss当泛化成功 |
| 参考覆盖和图像裁切风险 | 前8个hash参考无形态覆盖保证；CenterCrop可能截去细长部位；无原图不能证明当前错误由此造成 | 作为独立数据处理消融，主配置先保持不变 |

DEV父成员分数与父排名分数的Pearson相关性为known 0.952、near 0.995、extra 0.978；叶层为0.889/0.851/0.948。它提示当前拒识证据与分类相似度高度相关，不能仅凭此声称内部特征崩塌。
