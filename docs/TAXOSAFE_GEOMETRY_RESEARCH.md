# 冻结 reference 的层级相对几何：研究依据与实现边界

本方案对应新增的 `taxosafe_geometry` 路径。它复用 reference v3 的完整检查点和支持库，在冻结的 parent/fine 特征上估计层级相对 Mahalanobis 距离（下称 HRMD），补充原成员资格分数。原 reference、relation 和 CSSR-inspired 精修入口保留；本文件不把尚未运行的新方案当作已经取得的性能提升。

## 1. 新实验说明了什么

用户提供的 2026-10-03 07:55 UTC 两个评审包包含重训 reference 及冻结重构精修的结果。以下 TEST 分母按唯一图像内容计数。

| 指标 | reference | 重构精修 | 变化 |
| --- | ---: | ---: | ---: |
| 已知类端到端正确叶输出 | 423/450，94.00% | 419/450，93.11% | 减少 4 张 |
| 近域未知正确父类回退 | 124/204，60.78% | 128/204，62.75% | 增加 4 张 |
| 域外未知正确根拒识 | 220/272，80.88% | 220/272，80.88% | 不变 |
| 开放场景叶输出精确率 | 423/509，83.10% | 419/497，84.31% | 增加约 1.20 个百分点 |

DEV 上，已知正确数同为 198/219，近域正确回退由 30/69 增至 35/69。因此上次精修的开发集启用条件成立，但没有保证 TEST 已知样本不下降。新增误拒和原有误拒之间的变化，应依据逐图对照分析，不能只看最终净计数。

重构模块只使用 1,610 个已知 TRAIN 特征，最佳内部验证 NLL 约 0.0124，最佳轮数为 6。这个内部验证来自原 TRAIN 的图像划分，而冻结编码器已经见过原 TRAIN；它既不是主干独立验证，也不是未知物种验证。低 NLL 表明辅助已知分类容易拟合，不能证明重构分数能区分相似未知物种。

上一方案冻结父门，在该 DEV 上最多只有 52/69 张近域未知同时具有正确父候选并通过父门；即使叶层完全拒识，正确父回退仍不能达到 59/69 的 85% 要求。域外根拒识也不可能因仅增加叶门而提高。新方案因此需要同时研究父成员证据和叶成员证据，而不能继续只在冻结父门之后增加一个 veto。

原验收定义保持不变：已知端到端准确率严格大于 90%，近域正确父回退至少 85%，域外根拒识严格大于 90%，开放叶精确率严格大于 90%。近域输出根拒识、域外输出父类，均不能记为对应层级的正确结果。

## 2. 文献路线比较

### 相对 Mahalanobis：本轮实际借鉴的方法

Ren 等，**A Simple Fix to Mahalanobis Distance for Improving Near-OOD Detection**，2021。

- [作者论文](https://arxiv.org/abs/2106.09022)
- [UDL 2021 作者论文 PDF](https://www.gatsby.ucl.ac.uk/~balaji/udl2021/accepted-papers/UDL2021-paper-007.pdf)

该工作分析普通 Mahalanobis 距离在 near-OOD 上的失效，并减去一个类别无关背景距离，形成 relative Mahalanobis distance。这里应准确标注为 2021 年作者论文/UDL workshop 工作，不能标成 CVPR 或 TPAMI 论文。它为“比较类别特有结构与背景共同结构”提供依据，且不要求重新训练原分类主干。

本项目把“全局背景—类别”改为“全局背景—父类”与“父类背景—物种”两级对照。层级背景、固定候选评分、协方差收缩和与旧成员分数融合均属于本项目的适配设计，并非原论文完整复现；原论文的提升幅度不能迁移为本项目承诺。

### Mahalanobis++：归一化特征的依据

Müller 与 Hein，**Mahalanobis++: Improving OOD Detection via Feature Normalization**，ICML 2025。

- [PMLR 官方论文页](https://proceedings.mlr.press/v267/muller25a.html)
- [作者论文](https://arxiv.org/abs/2505.18032)
- [作者代码](https://github.com/mueller-mp/maha-norm)

论文将不同模型上距离检测表现不一致与特征范数变化联系起来，检验了先做 L2 归一化再拟合距离模型的做法。本项目的 parent/fine 特征本身已经归一化；几何模块仍独立校验并归一化输入副本，不修改原分类分数。论文支持这一设计选择，但不能证明当前浮游动物每个物种服从单一高斯分布。

### 细粒度 OSR：保留强分类证据，而不是假定层级自动解决拒识

Lang 等，**From Coarse to Fine-Grained Open-Set Recognition**，CVPR 2024。

- [作者项目页](https://langnico.github.io/fine-grained-osr/)
- [CVF 论文](https://openaccess.thecvf.com/content/CVPR2024/papers/Lang_From_Coarse_to_Fine-Grained_Open-Set_Recognition_CVPR_2024_paper.pdf)

作者在不同语义距离的细粒度生物类别划分中发现：最合适的开集分数取决于未知类与已知类的相似程度，层级表示对粗粒度拒识有帮助，但对细粒度拒识帮助有限。其研究还指出 familiarity 分数在细粒度条件下有优势。本项目据此保留已经表现较好的 reference 分类和成员资格证据，只增加可禁用的相对几何证据。没有实施该论文的层级对抗训练，也没有把父类更容易识别误解为物种更容易拒识。

### kNN 与 NNGuide：评估过，但本轮不叠加

- Sun 等，**Out-of-Distribution Detection with Deep Nearest Neighbors**，ICML 2022：[官方论文](https://proceedings.mlr.press/v162/sun22d.html)。非参数近邻可避免单一分布形式的限制。
- Park 等，**Nearest Neighbor Guidance for Out-of-Distribution Detection**，ICCV 2023：[CVF 论文](https://openaccess.thecvf.com/content/ICCV2023/papers/Park_Nearest_Neighbor_Guidance_for_Out-of-Distribution_Detection_ICCV_2023_paper.pdf)，[作者论文](https://arxiv.org/abs/2309.14888)。该工作明确讨论近邻距离对 near-OOD 的不足，并使用近邻信息指导分类器置信度。

近邻与多原型适合表达姿态等多模态变化，但本数据需要同时决定邻居数量、类别密度归一化、少样本半径和层级聚合方式。为了能判断收益来自何处，本轮只实现 HRMD；kNN、多个协方差模型选优和局部 token 重构没有混入默认方案。若未来单独研究近邻，必须作为预先声明的消融，使用 TRAIN/DEV 选择，不能看 TEST 后追加一个更有利的分数。

## 3. 两个层级的相对几何分数

令归一化冻结 parent 特征为 \(z_p\)，fine 特征为 \(z_f\)，reference 原规则给出的候选父类和物种为 \(p^*,c^*\)。候选身份保持不变。平方 Mahalanobis 距离记为：

\[
 D(z;\mu,\Sigma)=(z-\mu)^\top\Sigma^{-1}(z-\mu).
\]

在已知 TRAIN 的 parent 空间估计父类均值 \(\mu_p^P\)、所有图像的均值 \(\mu_0^P\)、共享父类内协方差 \(\Sigma_P\) 和全局协方差 \(\Sigma_0^P\)：

\[
 g_p(z_p,p^*)=D(z_p;\mu_0^P,\Sigma_0^P)
 -D(z_p;\mu_{p^*}^P,\Sigma_P).
\]

父分数衡量当前父类解释相对于全局背景解释的优势，用于决定是否应该输出根拒识。它不是父类 softmax 概率，也不重新选择父候选。

在 fine 空间估计物种均值 \(\mu_c^F\)、共享物种内协方差 \(\Sigma_C\)、父类均值 \(\mu_p^F\) 和共享父类内协方差 \(\Sigma_{FP}\)。若候选父类下至少有两个有 TRAIN 支持的已知物种，使用：

\[
 g_l(z_f,c^*)=D(z_f;\mu_{p(c^*)}^F,\Sigma_{FP})
 -D(z_f;\mu_{c^*}^F,\Sigma_C).
\]

这里比较“仅符合父类共同形态”与“符合某个具体物种”的程度。父类下只有一个有支持的已知物种时，没有可用的同父物种背景对比，明确改用 fine 空间的全局均值及全局协方差 \(\mu_0^F,\Sigma_0^F\) 作为背景。报告应记录哪些父类使用了这个回退；不能将其描述为已经学到该父类的未见兄弟物种。

因此模型共需要五个共享协方差：parent 空间两个，fine 空间三个。每个层级共享协方差都按全部已知 TRAIN 样本池化；不为每个小样本物种估计单独的 512×512 矩阵。协方差按以下固定形式收缩，避免高维小样本矩阵不可逆：

\[
 \widetilde\Sigma=(1-\lambda)\Sigma
 +\lambda\frac{\operatorname{tr}(\Sigma)}{d}I+\epsilon I,
 \qquad\lambda=0.1.
\]

实现通过稳定的线性代数求解距离。零范数、非有限值、缺失支持类别和类别映射冲突必须被识别，不能悄悄生成高置信度输出。均值、协方差及其计算所需特征均只来自已知 TRAIN。该阶段是确定性的统计拟合，没有新网络损失、梯度训练或额外未知类样本训练。

## 4. 分数融合与路由

原成员分数与几何分数不具有相同数值尺度。使用已知 TRAIN 上的中位数和带稳定下限的 MAD 等稳健尺度统计，分别进行中心化和缩放。尺度退化时采用实现中明确记录的回退，不以 DEV/TEST 分布重估统计。记对应标准化函数为 \(R\)，两层分别融合：

\[
 s'_p=(1-\alpha_p)R(s_p)+\alpha_pR(g_p),\qquad
 s'_l=(1-\alpha_l)R(s_l)+\alpha_lR(g_l).
\]

两个权重均仅考虑预先声明的 \(\{0,0.5,1\}\)。九组组合中排除两个权重同时为零的纯阈值重选，另将原始路由保留为精确回退方案。父、叶阈值在 DEV 上联合选择。先检查父门；父门不通过输出根，通过后再检查叶门；叶门不通过输出原候选父类，通过输出原候选物种。新父门可以改变原先的根/父判断，因而突破“父阈值完全冻结”的上限；它不能修复原候选父类本身选错的问题，候选身份上限仍需报告。

HRMD 是新成员证据，不是仅修改旧阈值。权重为零的方案仍有价值：它告诉我们几何证据没有提供足够增益。完全回退时直接调用原基线路由，恢复原始阈值和逐图决策，不通过浮点数标准化近似模拟旧输出。

## 5. 开发集保护与来源留出诊断

开发集选择至少受以下硬约束：

1. 每一张被基线正确识别的 DEV 已知图像仍必须正确，而不是只要求总正确数不下降。
2. 每个 DEV 近域物种的正确父回退数、每个 DEV 域外来源的正确根拒识数都不低于基线，避免大来源的提升掩盖小来源退化。
3. 开放叶输出精确率不低于基线，原四项验收门槛继续单独报告。
4. 要有开发集上的有效改善；没有满足保护条件且改善的候选时恢复原基线。

每次留出一个未知来源作诊断时，该来源不参与该折基线校准，也不参与新路由的权重、阈值网格或选择。每折从 fitting sources 重新拟合基线阈值，再重新选择该折几何融合的**两个权重及两个阈值**；不能固定由全部 DEV 选出的权重再称其为来源留出。各折可共享的仅是冻结基线模型、已知 TRAIN 拟合的几何统计和预先声明的算法规则。除各来源正确数不退化外，启用新路由还需要至少两个不同的留出来源正确数严格增加，不能由全折回退基线或仅一个来源改善来通过保护检查。整体验证不稳定时禁用新路由，并保留明确的失败原因和诊断。

最终部署参数来自全部 DEV，来源留出结果审计的是参数选择过程，不是这个最终参数实例的独立无偏泛化估计。这仍是**冻结编码器和固定 TRAIN 几何模型上的校准来源留出**，不是重训主干的严格留物种实验，也不是所有未来来源上的统计保证。DEV 只有少量未知来源，逐图保护和逐来源保护都只对观测到的 DEV 成立。它们降低过拟合风险，但不能保证 TEST 已知准确率仍为 94%，更不能保证四项指标全部达标。

## 6. 必须保留的验证与限制

应对比同一 reference 的原始结果与 HRMD 结果，并分别输出父/叶原成员分数、纯几何分数、融合分数及候选身份。拒识指标和路由指标分开：更高的未知拒识率不一定是更高的正确父回退率；更高的叶精确率可能来自拒绝了更多样本，应同时报告已知覆盖与正确数。

核心消融包括原基线、只启用父几何、只启用叶几何、联合几何。它们是预先声明的开发集研究路径，不能以 TEST 挑选最终模型。最终性能结论仍需实际 GPU 推理、逐物种对比和多 seed 重复；单元测试验证的是实现、不变量和协议，不能替代识别效果实验。

HRMD 仍依赖冻结全局特征包含可区分形态信息，也仍有共享协方差近似。如果图像主体裁剪、分辨率或形态信息在全局池化前已丢失，距离模型不能恢复这些信息。下一步是否需要原始局部特征、图像处理或表征训练，应由独立消融证明；本轮没有重新引入此前高度重复的 learned local token，也没有修改原网络与旧损失函数。

目前交付的是已实现、可验证的新实验方案。新 TEST 结果尚未产生，不能把文献证据、DEV 保护条件或软件测试通过写成“细粒度拒识难点已解决”。
