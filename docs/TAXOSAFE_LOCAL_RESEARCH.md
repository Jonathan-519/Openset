## 从结果到改动

1. **全局分数排序改善，但受保护阈值不可行。** DEV 已知—近域 AUROC 从 89.48% 到 90.89%，并不意味着低分尾部已知图片与未知分离。在既定 8 组权重内，加密全部阈值边界仍无保护可行点。本次改为以原决策为锚点的双证据局部规则。
2. **父类之间分数尾部不同。** 使用共享规则与有足够已知 DEV 支持的父类规则，避免为 23 个已知物种分别拟合高方差阈值。区域由预测候选父类定义，不使用推理图片的真实标签或未知物种名称。
3. **根拒绝恢复与远域拒识冲突。** 逐动作留出会检查恢复规则对未见未知来源的代价；本次该动作在 Brachyura zoea larva 留出折损失 3 个正确根拒绝，被禁用。
4. **候选父类错误无法靠叶阈值修复。** 实现了细粒度排名和父类前二排名相互支持的父类修复候选，但本次 DEV 留出没有正收益，故没有启用。该结构性问题尚未解决。

## 为什么本次不修改网络与训练损失

当前有完整 reference 权重与逐图原始分数，能够直接检验校准改动；没有新的真实图片训练实验能够证明增加损失或解冻 backbone 会改善目标。冻结网络减少已知识别表征漂移，但不能消除路由造成的已知拒绝。本次 TEST 回放已观察到 6 张已知正确图片被新规则拒绝，必须披露。

后续表征学习实验应将父类定位与细粒度陌生性分开评估，可参考 CVPR 2024 的层级对抗思想做独立分支和消融；它可能与 TaxoSafe 的父类一致性目标冲突，不宜未经训练对照直接替换当前稳定分支。增加训练轮数、单纯收紧全局阈值或在 TEST 上对 Oithona 定制规则，都不能构成此次结果支持的解决方案。

## 可行性与限制

- 无额外 GPU 反向传播、训练轮数或新外部依赖；沿用已有特征和 4 个 TRAIN 标准化分数。规则推理成本很小，主要新增成本在 DEV 留出搜索。
- 原方法与新方法各自显式配置。类别数、分类树、输入参数和三类输出接口保持兼容；新增审计字段不覆盖原始证据。
- 不称为完全解决细粒度拒识。本次 near 仍为 64.71%，距离 ≥85% 有差距；Oithona 的正确回退进一步下降，父层错误仍是重点。
- DEV 来源仅 4 个近域、4 个远域，样本少且不均衡。逐来源保护、少样本区域回退与组件审查可以抑制明显不稳定规则，不能保证新的未知类别或新设备上的表现。
- TEST 已反复用于项目研发，不应将此次回放作为一次从未参与研究决策的最终独立测试。规则和动作筛选本次只使用 DEV；回放 TEST 后未据其表现改规则或配置。
